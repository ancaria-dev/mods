# mods

Официальный реестр модов для Sacred Gold и исходники четырёх модов из него.

Лаунчер подключает этот реестр сам, настраивать ничего не нужно. Вы выбираете
мод, лаунчер скачивает его, проверяет и кладёт в `<Sacred Gold>/mods`.

Реестр — это обычный Git-репозиторий с индексом в корне. Такой же можно
завести для своих модов, и игроки подключат его по ссылке.

## Как начать

### Установить мод

1. Откройте лаунчер и перейдите во вкладку Available.
2. Нажмите Install у нужного мода.
3. Нажмите Play.

### Подключить другой реестр

Лаунчер принимает HTTPS-ссылку для клонирования, которая оканчивается на
`.git`. Для приватного репозитория укажите токен доступа.

### Предложить свой мод

Опубликуйте мод в своём реестре по схеме [SRML](#srml). Игроки смогут
подключить его сразу. Чтобы мод появился в каталоге на сайте, нажмите Submit
your mod на странице [ancaria.dev/mods](https://ancaria.dev/mods).

## Моды

| Мод | Что делает |
|---|---|
| [`self-check`](self-check) | Проверяет, что загрузчик работает. Подписывается на все события и показывает окно с 50 сценариями. У каждого есть подсказка, как его пройти: белый — ещё не проверен, зелёный — пройден, красный — результат неожиданный. Рядом панель с данными героя. |
| [`tracer`](tracer) | Записывает каждое событие в `<Sacred Gold>/logs/logs-<time>.txt`, по файлу на запуск. Видит окончательный ответ модов, но изменить его не может. |
| [`old-huge-potions`](old-huge-potions) | Превращает подобранное зелье в полноразмерное того же вида. Меняется только тип, поэтому цена и действие остаются прежними. |
| [`all-my-runes`](all-my-runes) | Превращает руну чужого класса в копию одной из рун вашего героя. Сначала подберите хотя бы одну свою руну. Незнакомые руны мод не трогает. |

Все четыре мода работают вместе и не конфликтуют. Каждый видит, что решили
моды до него, и `self-check` не вмешивается, если событие уже решено.

## SRML

Sacred Repository Mod Layout, версия 1. Реестром считается любой
Git-репозиторий с файлом `sacred.mods.repository.json` в корне. Этот выглядит
так:

```
sacred.mods.repository.json   индекс, генерируется
registry.toml                 описание реестра, пишется руками
icon.png                      иконка реестра
<id>/                         мод: код, build.gradle.kts, icon.png
```

Каждый мод остаётся обычным Gradle-проектом. Назовите его папку по
идентификатору мода, и `coderpack index` добавит в индекс пути `source` и
`icon`. При другом имени этих полей не будет. В реестре из одного мода
корневой `icon.png` служит иконкой мода.

Индекс руками не редактируют. Данные о моде генератор берёт из
`META-INF/declaration.toml` внутри собранного jar: идентификатор, название,
версию, описание, совместимость, авторов, сайт и конфликты. Название, сайт,
иконку и шаблон ссылки на релиз он берёт из `registry.toml`. Имя файла,
размер, SHA-256 и ссылку на скачивание он вычисляет сам.

```
coderpack index           сгенерировать индекс
coderpack index --check   проверить, ничего не записывая
```

Свой реестр собирается так же. Заполните `registry.toml`, соберите моды и
запустите `coderpack index`.

## Сборка

Нужен JDK в `PATH`. Моды компилируются под Java 21.

```
gradlew assembleSacredMod
```

Команда собирает все четыре мода, проверяет их линтером и кладёт jar в
`<мод>/build/sacred-mod/`. Чтобы сразу установить их в игру:

```
gradlew installSacredMod -PsacredDir="C:/Games/Sacred Gold"
```

Плагин `dev.ancaria.coderpack` приходит из Gradle Plugin Portal, API — из Maven
Central. Обе версии закреплены в `gradle/libs.versions.toml`. Maven Local
проверяется первым, поэтому `publishToMavenLocal` в `build` или `coderpack`
позволяет попробовать ещё не выпущенное изменение.

## Релизы

У каждого мода свои релизы с тегом `<id>-v<версия>`. Чтобы выпустить мод,
поднимите его версию в `build.gradle.kts` и запушьте в `master`. CI соберёт
моды, обновит индекс, закоммитит его и выпустит релиз, если такого тега ещё
нет.

Индекс описывает именно тот jar, который отдаёт ссылка на скачивание. Перед
установкой лаунчер сверяет SHA-256, читает дескриптор и проверяет
совместимость. Файл, который не прошёл проверку, в папку модов не попадёт.
